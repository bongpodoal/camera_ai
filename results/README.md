## 모델 비교 (같은 조건: 카메라 30fps, 기록 + 이미지 저장)

| 모델 | 입력 | 계산량 (640²) | 칩 FPS | 총 지연 | 칩 안 지연 | PC 지연 |
|---|---|---|---|---|---|---|
| YOLOv6n | 512×384 | 약 11 GFLOPs | 21.41 | 372 ms | 371 ms | 6.9 ms |
| YOLOv8n | 512×288 | 8.7 GFLOPs | 19.27 | 415 ms | 419 ms | 5.8 ms |
| 신호등 YOLO11s | 512×288 | 21.4 GFLOPs | 9.75 | 821 ms | 819 ms | 6.6 ms |

칩 FPS·총 지연은 원래 PC 기록, 칩 안·PC 지연은 두 번째 PC의 `latency_3models/` (10초) 값이다.
