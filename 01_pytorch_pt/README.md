# ① PyTorch .pt — 학습된 원본 모델

예제 모델의 원본 가중치는 **받은 파일에 없다.** 아카이브에는 이름만 남아 있다.

| 예제 | 아카이브에 남은 이름 |
|---|---|
| `yolov6-nano` (예제 기본값) | `yolov6n-r2-384x512` |
| `luxonis/yolov6-nano:r2-coco-512x288` | `YOLOv6_Nano-R2_COCO_512x288` |

| 분석할 것 | 상태 |
|---|---|
| 원본 출처 (YOLOv6 "R2"가 어느 릴리스인지, COCO 80클래스 학습) | 미확인 — 추정: Meituan YOLOv6 v2.0 nano |
| 원본 .pt 확보 여부 | 미확인 |

이 폴더에는 아직 파일이 없다. 원본을 확보하면 여기에 둔다.
