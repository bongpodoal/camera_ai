# ④ .blob — Myriad X 전용 실행 파일

예제는 블롭 하나가 아니라 **superblob**(SHAVE 개수별 블롭 묶음)을 쓴다.
실제 파일은 `05_nnarchive/example/*/` 안에 있다 (`fetch_example.py`가 풀어 둠, git에는 올리지 않음).

## superblob 구조 (실측)

```
[헤더 136 B = 빅엔디언 u64 × 17] [기본 블롭] [SHAVE 1 패치] … [SHAVE 16 패치]
 └ u64[0] = 기본 블롭 크기, u64[1..16] = SHAVE 1..16 패치 크기
```

| 항목 | yolov6-nano (기본값) | r2-coco-512x288 |
|---|---|---|
| 파일 크기 | 8,726,870 B | 8,721,232 B |
| 기본 블롭 | 8,685,208 B (SHAVE 8로 컴파일, 패치 0) | 8,681,560 B (SHAVE 8) |
| 패치 크기 범위 | 1,146 ~ 11,562 B | 1,123 ~ 11,121 B |
| 크기 합 검증 | 일치 | 일치 |
| 컴파일 | `compile_tool 2022.3.0 -d MYRIAD -ip U8` | 동일 |
| CMX 슬라이스 | 8 | 8 |

`-ip U8` = 칩은 8비트 정수 이미지를 그대로 받는다. ÷255 변환은 블롭 안에서 한다 (③).
depthai는 실행할 때 남는 SHAVE 수에 맞춰 기본 블롭에 패치를 적용한다.
